# 공공데이터 표본

원본은 `raw/`, 정규화 자료·품질 결과·지도 표본은 `processed/`에 둔다. 둘 다 Git에서 제외한다. 기본/기능별 자료 생성은 [데이터 준비 안내](../docs/data-setup.md)를 따른다. 출처·스냅샷 메타데이터와 일부 경계는 `reference/`에 보관한다.

2026-09-29 확인한 원천은 소상공인시장진흥공단 상가정보(15083033), 국토교통부 버스정류장 위치정보(15067528), 진주시 CCTV위치정보(15143299)다. 세 카탈로그 모두 이용허락범위 제한 없음으로 표시됐다. 각 실행의 정확한 URL·자료 시점·조회 시각·SHA-256은 다운로드 manifest에 남긴다.

좌표 선별은 넓은 진주 주변 범위를 이용한 오류 탐지다. 행정경계 포함 검증이나 모든 위치의 정확성 검증을 뜻하지 않는다. CCTV의 동일 위치 반복 행은 여러 카메라일 수 있어 원본/정규화 자료에서 삭제하지 않고, 지도 표본 선택에서만 겹치는 위치를 피한다.
