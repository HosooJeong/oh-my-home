# 조건 충족도 보고서

결과의 같은 마을에서 건물(중앙 집은 총평)을 누르면 분야별 평가로 전환한다. 상태 버튼과 탭으로도 선택할 수 있고, 탭은 방향키/Home/End로 이동한다. 집 선택을 바꾸면 그 후보의 검증된 측정값·조건과 차트·비교 이유를 함께 표시한다.

## 차트 의미

- 2026-10-03부터 육각형 축은 생활·장보기 / 교통·동선 / 교육·육아 / 건강·의료 / 여가·관계 / 식사·외식이다. 안전·비용과 기타 추가 요구 분야는 별도 평가 탭에 보존한다. [분류·모듈·자료의 범위](six-category-access.md).
- 목표는 각 사용자의 utility ideal을 충족하는 수준 100이다. 카테고리 중요도(비중)를 목표 높이로 사용하지 않는다. 표시명은 주관적 만족도 대신 `확인된 충족도`다.
- 분야 내 충족도는 기존 개인 utility fit와 원래 조건 비중의 가중 평균이다. 기존 전체 점수·비중·필수 판정·순위는 수정하지 않는다.
- 수치 근거가 모두 확인된 분야만 점을 표시한다. 미확인 조건 비중은 분모에 남겨 가능한 하한/상한을 점선 범위로 표시한다. 미확인/미선택 축을 0점으로 연결하지 않고, 0점이 검증된 경우에만 중앙에 점을 찍는다. 모든 축이 확인된 경우에만 면적을 채운다.
- 집·비용은 실거래 참고이며 충족도·현재 매물/예산 충족으로 수치화하지 않는다. 가격만 요청했으면 총평에 집별 충족도 미평가를 표시하고 비용 탭에서 기존 지역 거래 자료를 보여준다.
- 비중 0인 필수조건도 상세 평가에 유지한다. 필수 미확인 조건이 있으면 그 분야의 완전 충족 판정도 보류한다.

## 총평과 분야 평가

총평은 기존 전체 결과의 확인한 비중/필수/미확인·비교 이유를 요약한다. 목표 대비 80% 이상인 분야 최대 2개와 낮은 분야 최대 2개·미확인 분야 최대 2개는 보기 전환용 요약이며 새로운 점수·추천 규칙은 아니다. 분야 탭에서 목표, 현재 측정값과 차이, 조건 충족도, 원래 요구 및 필수조건을 표시한다. 시설/원문/날짜/출처는 접어서 보존한다. CCTV는 등록 참고이며 안전 점수가 아니다.

보완 인용은 검증된 요청 ID와 분야 연결로 나눈다. 연결이 없는 기존 인용은 총평의 접힌 조사 목록에서만 표시한다. 시설·지역 조사와 선택한 집의 적용 여부를 구분하고 정성 인용으로 수치 충족도/필수조건을 덮어쓰지 않는다. 탐색의 상가 격자 대표성 한계, 실제 집/매물·직선거리 한계는 기존 지도 영역에 유지한다.
