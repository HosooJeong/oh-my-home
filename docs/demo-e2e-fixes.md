# 두 집 비교 시연에서 확인한 수정 범위

2026-10-03. 여러 집 비교 → 실제 주소 선택 → 블록 선호 배치 → 5분야 자연어 입력 → 조건 확인 → 공공자료 비교 → 차트/평가 이유/출처 → 별도 출근 경로 조회를 실제 브라우저에서 시험했다. 제품 모델은 `gpt-6.1-sol` / `medium`을 유지한다. 사용자 입력과 원래 모델 반환을 수정하지 않는다.

- “가격은 순위 점수에 반영하지 않아도 괜찮아요”라는 제외 의사를 검증 규칙에서 인정한다. 아직 가중치나 필수조건이 남아 있는 항목을 제외하는 응답은 계속 거절한다.
- 실거래 참고/가격 점수 제외의 같은 명시적 의사가 반복될 때 같은 housing context에 원문 두 개를 연결할 수 있다. 키/값/양쪽 원문의 의미가 일치하는 경우만 허용하고, 공원 등 다른 요구를 이 예외로 덮지 않는다.
- 진주라는 도시 범위와 그 안의 명시적인 준비된 법정동은 하나의 실거래 조회 범위로 다룬다. 서로 다른 동/다른 도시/미지원 필터의 충돌은 계속 확인을 요구하며 조회 범위를 넓히지 않는다. 원래 profile은 그대로 보존한다.
- [경로 확인](route-api.md)에 정확한 출발/도착 주소 검색을 추가했다. 경로는 화면 표시 전용이고 제품 LLM·대화 기록·순위 점수에 넣지 않는다.

관련 Python 69검사와 경로 JS 구문 검사 통과. 실제 최초 조건 제외 실패, 자동 안내문 재질문, 도시/동 중복 조회 충돌을 먼저 재현하고 수정했다. 최종 같은 조건의 정리 50.651초 → 질문 0 → 확인 → 두 집 결과/available, 가격 참고 804건을 확인했다. 앞선 실패 및 중간 결과를 전체 성공으로 바꾸어 기록하지 않는다.

실제 주소·소속과 영상 캡처는 상위 작업 공간의 시연 자료에만 두며 코드 저장소에 개인 좌표/디버그 대화/비밀키를 넣지 않는다. 두 집의 물리적 상태나 실제 거주 만족도를 조사한 시험이 아니며, 선택한 조건의 공공 등록자료 비교다. 실제 경로 예상시간은 별도 참고이고 현재 순위는 등록좌표의 직선거리 기준이다. 시연 영상은 연속 실시간 녹화가 아닌 실제 검증 화면 캡처를 편집한 자료다.
