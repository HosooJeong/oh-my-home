## 개인 조건과 평가

| 지표 | 조건 | 확인 범위 |
|---|---|---|
| `park_straight_line_distance_m` | 전체/어린이/근린공원, 개인 거리 기준 | 지정 유형의 진주 등록 장소까지 직선거리 |
| `library_straight_line_distance_m` | 공공·작은/공공/작은도서관, 개인 거리 기준 | 학교/대학도서관 제외, 실제 출입 가능성 미확인 |
| `meeting_straight_line_distance_m` | 사용자 지정 이름·위도·경도 | 해당 지점 직선거리, 외부 출처 URL을 만들지 않음 |
| `hobby_suitability` | 종목·이용 형태·개인 중요도 | 등록 후보·웹 보완, 현재 점수 미지원 |

화면의 500m/1500m·중요도는 편집 제안이며 적용 전 개인 기준으로 확정하지 않는다. 분야 비중 × 분야 안 조건 비중을 사용하고 시설 규모/개수에 일괄 가점을 주지 않는다. 미지원/불확실 조건의 비중을 보존해 전체 순위를 유보한다. 중요도 0은 평가 제외이며 필수조건은 유지한다.

자료 365일 이내는 초기 구현 선택이다. 선택 유형에 오래된/미래/좌표 누락 행이 있으면 완전한 최신 최단거리 점수는 유보하고 등록 최근접만 참고로 표시한다. 이번 도서관 73곳이 오래된 행이다. 자료 공백은 시설 없음/조건 나쁨이 아니다. 진주 밖 시설·출입구·실제 경로/도보 시간·좌석 여유·동반 규칙은 미확인이다.

만남 지점은 `source_kind=user`로 구분하며 기존 공공 근거의 출처 검증은 유지한다. AI 응답 좌표는 요청/인터뷰에 명시한 위도·경도와 대조하고 모델이 장소 이름으로 지어낸 좌표는 수용하지 않는다. 개인 지점/좌표는 취미 웹 조사에 보내지 않는다.

## 사설 취미시설 보완

- 헬스·필라테스·탁구·수영·테니스·요가와 직접 입력 취미, 요청한 PT/기구·매트/개인·그룹/자유 이용·레슨 등의 형태를 보존한다. 상호/업종만으로 실제 형태를 확정하지 않는다.
- 기존 2026-06-30 상가 분류는 헬스98, 요가/필라테스 공동 업종152, 탁구17, 수영5, 테니스24행이다. 요가와 필라테스152는 같은 행을 각각 조회하므로 합산하지 않는다. 전체 시설 수/현장 영업 확인값이 아니다.
- 후보별 등록 최대3곳 참고를 표시한다. 웹 입력은 최대3종목·공개 행정동3개·종목당 등록2곳(합계6곳)이다. 종목명이 상호에 있는 후보를 먼저 보고 거리로 좁힌다. 직접 입력 취미를 여러 개 요청하면 첫 종목을 조사하고 미조사 수/나머지 니즈를 보존한다. 공통 후보 자동 생성은 기존 생활/교통 범위이며 M6 조건 선별은 미지원이다.
- 비교 뒤 요청된 보완에서 LLM이 직접 검색하며 등록 목록 밖 시설도 발굴한다. 공개 도시/동·종목/형태·등록 상호/주소만 보내고 후보 좌표·개인 원문·키·지도 Local/리뷰는 보내지 않는다. 메인은 상가/교육→안전→여가 순으로 요청을 처리하고 실패를 격리한다. 취소와 같은 근거의 재가중치를 지원한다.
- 공개 HTTPS 원문에 robots·텍스트 형식·크기/시간·공개 DNS·리디렉션 제한을 적용한다. 초기 제공처 제한으로 카카오/네이버/다음 전체 도메인과 Instagram/Facebook/YouTube·로그인/비공개 주소를 제외한다. 해당 플랫폼의 블로그/공식 채널까지 연결됐다는 뜻이 아니다.
- 원문 지점명·진주 도로명주소·종목·인용을 대조하고 최대6개 발견 후보/같은 지점·종목 중복 제거/출처당 총20단어·인용160자 제한을 적용한다. 실제 웹 도구 사용이 없으면 수용하지 않는다. 운영자 안내/일부 이용자의 경험/AI 분류·해석을 구분한다.
- 원문 작성일과 메타데이터 일치·730일 이내 인용만 채택한다. 수정일/확인일로 대체하지 않으며 협찬/체험단 경험·오래된/미래/날짜 충돌·다른 지점/종목·조작 인용은 제외한다. 작성일 없는 운영자 소개는 **발견 후보만** 남기고 인용/최신 이용 근거로 쓰지 않는다. 작성일 없는 경험은 제외한다.
- 정확한 상호/주소는 공개 등록 ID로 연결할 수 있지만 모델 좌표/정량 승격은 수용하지 않는다. 검색 건수는 전체 개소 수가 아니고 웹 인용은 점수·필수조건 통과·전체 만족도에 반영하지 않는다. 현재 이용·운영자 소유 관계·원문의 모든 주장까지 검증한 것은 아니다.

개별 영업시간/휴무/폐점 조사는 없다. 상가 지속 갱신은 [데이터 관리](data-maintenance.md)에 남긴다. 현재 프로그램/모임·관계 형성·동반 규칙·예약/잔여석·실제 수업 형태의 정량 평가는 후속이다.

## 검증 범위

변경 관련 고유82건(여가18·교육10·공통코어23·후기16·안전15), JS 문법, 실제 원본, 합성 요청의 실제 AI 니즈/웹검색과 핵심 브라우저 흐름을 확인했다. 실제 취미 검색은 웹 도구5회/수용 후보0곳이다. 양성 원문 수용/오류 거절은 합성 검사이며 실제 인용 확보 성공과 구분한다. 전체 회귀/반응형 반복/실사용자·현장 검증은 수행하지 않았다. 증거/버전은 상위 기준 기록 `LEISURE01`을 따른다.

R4 후속: 지점·종목 발견과 요청 이용형태/해석의 근거를 구분한다. 기구/매트·소그룹/개인·자율/대관 등 명시 형태가 인용에 없으면 미확인으로 남기고, 나머지 인용도 별도 검색 없는 Codex 검토와 응답 ID 대조를 수행한다. 맞지 않는 형태/근거 없는 건강 적합성·숙련도·관계 해석을 수용하지 않는다. 형태/해석이 확인되지 않아도 지점·주소·종목이 대조된 발견 후보는 `request_unverified`/인용 없음으로 남길 수 있다. 원문에 명시된 부정도 관련 근거이며 적합성 통과가 아니다.
