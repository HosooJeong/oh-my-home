# AI가 실제 이용 조건을 확인하는 흐름

2026-10-03 구현. 학원 과목·대상 학년·수업 형태와 의료기관의 실제 진료과는 등록 업종이나 가까운 거리만으로 대신 확인하지 않는다.

1. 자연어 선호에서 확인할 기능 조건을 추출한다. 학원/의원 이용 선호는 별도의 '검색해 주세요' 없이 조사 질문으로 연결한다. 학교/약국 거리만 요청하거나 명시적으로 웹 조사를 끈 경우에는 불필요한 조사를 추가하지 않는다.
2. 최근 365일 이내 공공 등록자료에서 집 주변 시설 후보를 고른다. 학원의 학년이 불명확해 정량 개소 집계에서 제외된 시설도 **조사 후보**로는 유지한다. 의료기관은 원하는 진료과에 해당할 수 있는 등록 업종을 탐색하되, 업종 이름을 실제 진료과 확인으로 취급하지 않는다. 동물병원은 의료기관 후보에서 제외한다.
3. AI가 공개 웹을 직접 검색하고 운영자 홈페이지·공공기관의 개별 시설 안내를 읽는다. 검색용 입력에는 시설 공개 상호/주소와 비식별 질문만 포함한다. 등록 후보가 없거나 수용할 근거가 없으면 **진주시 공개 웹에서 시설을 추가 발굴**한다. 공공 경계로 확인한 행정동을 우선 탐색하며 집 좌표·가족 신상·개인 진단·지도 API 응답을 보내지 않는다. 상가 데이터에 없는 병원도 이 경로로 찾을 수 있다. 특정 시설명을 지정했는데 등록 후보와 연결되지 않으면 다른 시설로 대신하지 않는다.
4. 서버가 원문을 다시 읽어 상호·도로명 주소·짧은 직접 인용·자료 시점을 대조한다. 이어서 별도 AI 호출이 **그 원문 문맥만으로** 과목/진료과 값과 설명, 원래 질문과의 관련성을 검토한다. 원문이나 검토가 실패하면 미확인이다.
5. 교육/의료 결과 탭에서 시설명, 집부터의 **등록 좌표 기준 직선거리**, 확인한 과목/진료과, 쉬운 설명, 원문 링크와 확인 시점을 표시한다. 등록 후보는 각 집의 조사 반경과 연결한다. 웹에서 새로 발견한 시설은 좌표·집별 거리·생활권 적용을 미확인으로 구분한다. 요청과 관련된 근거를 찾았다는 사실을 모든 세부 조건 충족으로 표현하지 않는다.

## 조사 범위와 점수

과목/진료과 사실 확인과 방문자 평가는 분리한다. 종전 티스토리 후기 조사 경로는 일부 방문자의 경험 인용에 계속 사용한다. 학원의 과목이나 의료기관의 진료과는 후기 대신 운영자/공공기관 안내에서 확인한다.

2026-10-03 D71 보강: 공식 안내를 우선하되, 공개 학원·의료 정보 서비스의 개별 시설 항목도 읽는다. 외부 서비스는 `directory`로 구분하고 **그 서비스에 표기된 내용 / 운영자 확인 미확인**으로만 설명한다. 상호·주소·직접 인용·날짜/갱신일 미확인·별도 AI 검토는 계속 적용한다. 외부 표기를 실제 제공이나 선호 충족으로 확정하지 않는다. 의원급 후보가 있으면 비교 집별 의원을 먼저 배정하며, 공유 3곳 예산에서 의원2곳·병원1곳을 목표로 한다. 웹 발굴도 같은 방향이고 내과·소아청소년과가 서로 다른 의원에 있어도 각각 탐색한다. 병상 수나 '소규모' 자체는 추정하지 않는다.

이미 확인한 나이스 등록 과정의 문자 그대로인 과목·학령도 결과에 표시한다. 웹검색이 빈 결과여도 등록 과정은 지우지 않는다. `source_row`/시설ID·교육청 연계일을 함께 보존하고 연계일을 작성일이나 현재 모집 확인일로 바꾸지 않는다. 최근365일의 실제 과정 필드만 사용하며 상호나 일반 '보습' 과정에서 초등 수학 등을 추측하지 않는다. 공공 등록 과정은 AI가 생성한 해석이나 별도 웹 원문 검증으로 표시하지 않는다. 웹 보완과 정량 개소/거리·불완전 학원 목록의 점수는 그대로 분리한다.

시설 원문 상세 안에 카카오맵/네이버지도 검색 링크를 제공한다. 지도는 사용자에게 장소를 확인하는 통로이며 이번 보강에서 지도 상세/리뷰/API 응답을 수집하거나 LLM에 전송하지 않는다. 카카오 Local API의 응답은 장소명·분류·주소·좌표·상세 링크 등이며 상세 과목/학령 필드는 없다. [공식 명세](https://developers.kakao.com/docs/ko/local/dev-guide), [나이스 과정/공개 수강료 설명](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN19220231012134453534385&infSeq=1) (2026-10-03 확인).

학원 조사 반경은 확인된 조건의 반경을 사용하고 없으면 2km, 의료기관은 2km를 **서비스의 조사 범위**로 사용한다. 사용자 선호의 탈락 기준이 아니다. 각 비교 집에 후보를 우선 배정한 뒤 연구 종류별 최대 3곳, 시설당 최대 2개 사실, 호출당 최대 6회 검색을 목표로 한다. 해당 종류의 첫 웹 조사에서 수용 근거가 없을 때만 최대 3곳의 웹 발굴을 한 번 추가한다. 교육청 등록 과정이 표시되더라도 웹 근거가 없으면 추가 탐색을 막지 않는다. 각 조사별 최대 6개 원문 주장을 별도 AI 검토 한 번으로 확인한다. 한 시설이 여러 집의 반경 안에 있으면 한 번 조사한 사실을 각각의 등록 좌표 거리와 연결한다. 범위 밖·미조사 후보는 조사 계획에 남긴다.

웹검색 결과로 등록자료의 개소 수·최단거리·학령 불명확성을 덮어쓰지 않는다. 이번 기능은 **원문 근거가 있는 시설 이용 조건을 제공하는 단계**다. 정량 자료의 거리 점수와 별도로 표시하며 임의의 학원 만족도·의료 수준 점수를 만들지 않는다. 비교에 반영해야 하는 미지원 선호의 비중도 지우지 않는다. 부분 조사로 모든 조건이 충족되었다고 판정하는 기능은 지원하지 않는다.

## 날짜·출처 정책

작성일을 확인한 자료는 730일 이내이며 미래가 아닌 경우만 채택한다. 수정일/조회일·정보 서비스의 데이터 기준일/공공자료 연계일·수강료 적용일을 작성일로 꾸미지 않는다. 날짜 없는 운영자·공공기관·외부 정보 서비스의 시설 안내는 원문·상호·주소·인용을 직접 확인한 경우에만 **갱신일 미확인 / 직접 조회일**로 분리한다. 외부 서비스는 운영자 확인 미확인으로 추가 구분한다. 이는 현재 운영·진료 여부를 검증했다는 뜻이 아니다. 날짜 없는 블로그 글·개인 후기는 제외한다. 운영자 블로그도 날짜를 확인해야 한다. 공식 안내는 운영자의 제공 정보이며 임상적 추천이나 서비스 품질의 독립적 인증이 아니다.

원문 인용은 출처당 총 20단어/160자 이하다. 공개 HTML만 제한된 크기·시간 안에 읽고 robots 정책을 따른다. 로그인·지도 리뷰 복사·비공개/로컬 주소 요청은 허용하지 않는다. 원문이 막혀 있으면 다른 정보를 꾸며 채우지 않는다.

실제 실행 증거와 미확인 범위는 저장소 밖의 프로젝트 검증 기록에서 관리한다. 자동 검사/고정 응답 시험과 실제 모델·웹 호출은 구분한다.
