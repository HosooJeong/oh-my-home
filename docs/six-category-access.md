# 여섯 생활 분야와 완성된 차트

2026-10-03. 사용자는 육각형 보고서의 완결성을 위해 평가가 어려운 기본 분야를 교체해도 된다고 명시했다. 의료·식사를 새 기본 분야로 구현하고, 안전·비용은 기존 참고/추가 요구 기능으로 보존한다. 기존 M1~M6 개발 이력과 당시 검증 결과는 바꾸지 않는다.

| 기본 분야 | 이번에 계산 가능한 요구 | 계산으로 대신하지 않는 요구 |
|---|---|---|
| 생활·장보기 `living` | 등록 슈퍼마켓·편의점 접근성 | 재고, 매장 규모, 현재 운영 |
| 교통·동선 `transport` | 등록 버스 정류장 접근성 | 실제 통근 시간·배차·환승 |
| 교육·육아 `education` | 학교 접근성·지원 범위의 학원 선택지 | 배정·수업의 질·통학 안전 |
| 건강·의료 `health` | 등록 약국·내과/소아과 의원 접근성 | 진료 수준·응급 대응·다른 진료과 |
| 여가·관계 `leisure` | 지원 범위의 공원·도서관·지정 지점 접근성 | 취미시설 이용 조건·모임의 질 |
| 식사·외식 `dining` | 등록 평소 식사 업종·음식점 접근성 | 맛·가격·식단·알레르기 적합성 |

같은 효과를 다른 분야에 중복 산입하지 않는다. 장보기는 상품 구입, 식사는 음식점 이용, 여가는 공원/취미를 다룬다. 카페·주점·식료품 소매업을 식사 거리의 근거로 넣지 않는다. 하나의 평소 식사 요청에 일반 음식점 거리를 함께 자동 생성하지 않는다.

## 근거와 파이프라인

기존 `inventory.json`의 소상공인시장진흥공단 경남 상가 자료(2026-06-30 기준)를 다시 분류한다. 공식 [공공데이터포털 설명](https://www.data.go.kr/data/15083033/fileData.do)은 영업 중인 상가업소의 상호·업종·주소·좌표를 제공하며 분기별 갱신한다고 안내한다(확인 2026-10-03). 이 설명은 기준일의 등록자료 성격이며 실행일의 운영을 재검증했다는 뜻은 아니다. 다음 공개본이 나오면 원본 확보·무결성·정규화·업종 검사를 다시 수행한다.

`pharmacy_straight_line_distance_m`은 약국, `clinic_straight_line_distance_m`은 원본의 **내과/소아과 의원** 업종을 사용한다. 이 혼합 분류는 개별 진료과를 확정하지 못한다. 일반병원·동물병원·치과 등은 해당 의원 지표에서 제외한다.

`everyday_meal_straight_line_distance_m`은 백반/한정식·국/탕/찌개류·김밥/만두/분식, `restaurant_straight_line_distance_m`은 코드의 명시적인 음식점 업종 목록을 사용한다. 업종 명칭으로 영양·맛·가격을 추론하지 않는다.

LLM은 원문 선호를 해당 모듈/지표와 연결하고, 수치 없는 선호에는 기존의 수정 가능한 비교 척도를 제안한다. 모듈은 같은 후보들에 대해 최단 직선거리와 원본 행/기준일/출처를 반환하고, 기존 평가기가 개인 utility·비중으로 계산한다. 의료/식사의 새로운 조회에도 365일 이내이며 미래가 아닌 기준일을 요구한다. 가까운 기록이 오래됐다고 더 먼 최신 기록으로 슬쩍 바꾸지 않고 미확인으로 둔다. 지원하지 않는 이동/품질 요구는 누락하거나 거리로 대신하지 않는다.

보완 조사 요청이 있으면 동일 시설·요구에 연결한 공개 이용 정보 조사에 이어진다. 인용 검증·개인정보 제거·출처/시점 확인은 기존 규칙을 사용하고, 조사 결과는 점수에 넣지 않는다. 의료기관의 임상적 수준이나 치료 추천을 생성하지 않는다.

## 차트와 이전 입력

목표선은 각 분야의 개인 ideal을 충족하는 **100**이다. 블록 중요도는 전체 비교의 비중이며 차트 목표 높이와 별개다. 여섯 분야의 양수 비중 조건이 모두 검증되면 끝점과 시작점을 연결하고 면적을 채운다. 미선택/미확인 분야는 빈 축으로 남기며, 실제 검증된 0만 중심에 표시한다. 차트를 위해 점수를 만들거나 반드시 모두 선택하게 하지 않는다.

새 기본 블록은 1~6개 자유롭게 선택한다. 안전/CCTV·실거래가는 최종 입력 검토의 접힌 **추가 참고**에서 요청할 수 있고 결과의 별도 탭에 보존한다. 기존 초안의 안전/비용 원문은 추가 조건으로 보존하고 새 분야의 답변으로 바꾸지 않는다. 분류가 바뀐 기존 초안은 재검토를 거친다. 추가 요구까지 합쳐 입력 한도를 넘으면 원문을 자동으로 자르지 않고 수정 안내를 표시한다.
