# M5 안전·환경 첫 범위

2026-09-30. 메인 니즈/인터뷰 → 개인 중요도 → CCTV 등록 참고 → 필요한 공식 지역 웹 보완 → 메인 통합을 연결했다. 침수·재해/야간 보행/사고/소음/대기환경의 비교 요구는 미지원 조건과 비중으로 보존하고 전체 순위를 유보한다. CCTV나 웹 인용을 위험 점수·필수조건 통과 근거로 승격하지 않는다.

## 실제 조회 범위

[진주시 CCTV](https://www.data.go.kr/data/15143299/fileData.do), 공개본 수정일 **2026-09-16**. 기존 inventory **5,528행 / 서로 다른 정확한 좌표 3,896지점**, 좌표 오류 의심 3행 분리. 공개본 수정일은 관측일/현재 작동 확인일이 아니다. 좌표 지점 수는 카메라 대수·설치 시설 수가 아니다.

같은 좌표 행을 묶고 후보별 직선반경의 등록 행/좌표 지점 수·등록 목적·최근접 거리·원본 행 ID를 표시한다. 최근접은 반경 밖일 수 있다. 오류 분리 행과 원본 누락 때문에 전체 설치 현황을 보장하지 않는다. SGIS 2025-06-30 진주 읍면동 경계로 후보 지역을 확인한다. 경계 없음/밖은 unavailable/outside_scope로 반경 내 지점 0과 구분한다. 1년 넘은 공개본은 과거 참고로 표시한다(구현 선택).

`SafetyReferenceResult`는 references에만 반환한다. 메인이 프로필/후보 지문과 후보 ID를 검사한다. `SafetyModule.run`은 수치 Evidence 없이 미지원 조건을 반환한다. 재가중치는 기존 자료와 웹 결과를 재사용한다.

## 공식 웹 보완

요청한 경우만 비교 뒤 실행한다. 첫 제공처는 **www.jinju.go.kr의 개별 공개 게시글**이며 요청 문제의 사고·재해 사례/점검/예방 조치·계획을 보완한다. 인터넷 전체·전문기관 측정자료를 모두 조사한 것은 아니다.

검색에는 **공개 행정동 코드/이름과 선택한 문제 코드**만 전달한다. 개인 요청 원문/후보 좌표/지도 응답/키는 보내지 않는다. 최대3동(코드순), 동당 인용2개, 출처당 총20단어/160자, 검색4회 이내 목표(하드 제한 아님). 나머지 동과 확인하지 못한 문제를 표시한다. 비교의 보완 작업은 1회이며 상가/학원과 함께 요청되면 같은 취소 가능한 작업에서 순차 실행한다. 분야별 실패가 다른 검색이나 앞서 수용한 결과를 지우지 않는다.

공유 작성일 **730일 이내** 정책을 따른다. 공식 게시글의 info1 작성일과 substanceautolink 기사 본문/제목만 읽고 메뉴·꼬리말의 지역명/날짜는 제외한다. https 호스트/게시글 경로·ID, robots.txt, 원문 크기/시간 제한·리디렉션 차단, 작성일/원문 인용/행정동·문제 일치를 검사한다. 모호한 날짜·접근 불가·다른 동·오래된 자료·원문 불일치는 제외한다. 공식 발표와 인용에 한정한 AI 해석을 구분한다. 예방 계획은 실제 완료나 주택 안전 보장이 아니다. 보도가 없다고 사고 없음/안전으로 판정하지 않는다. 모든 해석의 정확성·조사 완결성을 보장하지 않는다.
