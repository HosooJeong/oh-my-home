# M4 학교·학원 접근성과 조건부 웹 조사

2026-09-30 구현 범위: 학교급별 공식 위치와 직선거리, 학령·과목·반경별 등록 학원 선택지, 개인 기준·가중치 편집, 필요할 때만 이어지는 LLM 웹 보완. 통학구역 배정·학교 출입구·실제 보행 경로·횡단/유동인구·안전·돌봄·현재 모집·실제 반 크기는 미지원/미확인이다.

## 자료와 계산

- [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)의 전국 12,011행에서 진주 운영 초·중·고 90행을 선별했다. 진주 행의 데이터기준일은 2026-03-20. 학교 ID·원본 행·공식 위경도를 보존한다. 공개 JSON 다운로드를 사용했으며 이번 확인에서 개별 이용허락 문구는 확보하지 못했다. 전체 원본/정규화 파일은 Git에 포함하지 않는다.
- [NEIS 학원교습소정보](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN19220231012134453534385&infSeq=1)의 경남 S10/진주 1,228행을 공식 다운로드로 확보했다. 무인증 hub API의 5행은 표본이므로 전체 목록으로 사용하지 않는다. 공식 페이지는 주간 갱신·이용허락 범위 제한없음을 표시했다. 성인 전용 6행을 제외해 1,222개 등록 ID를 보존한다. 같은 NEIS 원천의 표준데이터를 중복 합산하지 않는다.
- 학원 좌표는 NEIS에 없어 공공 상가 inventory의 **같은 도로명 건물 주소**와 연결했다. 건물 내 좌표 편차가 50m를 넘으면 연결을 유보한다. 1,007개소 연결, 미연결 215개소(좌표 충돌 83 포함). 실제 학원 입구/층 위치는 아니다. inventory 해시가 달라지면 다시 정규화해야 한다.
- 공식 과정 목록/교습 설명에서 과목과 학령을 확인한다. 상호만으로 과목·대상 학년을 추정하지 않는다. 시설 ID로 집계하므로 과정 수가 여러 개소가 되지 않는다.
- 자료 시점은 학교 `REFERENCE_DATE`, 학원 `LOAD_DTM`(NEIS 연계일)을 사용한다. **다운로드 날짜를 행의 최신성으로 대체하지 않는다.** 자료 기준/연계일 및 건물 좌표 기준일이 365일을 넘거나 미래이면 수치 확정을 유보한다. 현재 오래된 학원 행 761개소. 연계일은 실제 영업 상태 확인일이 아니다.

| metric | parameters | utility |
|---|---|---|
| `school_straight_line_distance_m` | `school_level`: elementary/middle/high, 선택적 `school_id` | m/lower, 사용자 목표·만족도 0 거리 |
| `academy_count_within_radius` | `school_level`, `subject`: math/english/korean/science/art/music, `radius_m`: 숫자 문자열 | count/higher, 충분한 개소 수 ideal / 만족도 0 기준 limit |

학교는 최근접 직선거리이며 배정/입학 가능성이 아니다. 학원 수의 만족도는 충분한 선택지 수에서 포화한다. 큰 등록정원은 높은 점수로 바꾸지 않는다. 등록정원·일시수용인원은 실제 반 크기/현재 수강생 수와 구분한다. 위치·학령·시점 누락으로 범위의 전체 수를 확정할 수 없으면 확인된 하한 개소 수만 표시하고 점수/전체 순위는 유보한다. 미확인 시설은 해당 반경에 포함되는지도 불명확할 수 있다. 자료 없음과 확인된 0개소를 구분한다.

## 니즈와 보완 파이프라인

요청/필요 인터뷰 → 개인 조건·중요도 → 동일 후보에 공식 조회/수치 계산 → 메인 근거 통합 → 정성 조사 요청이 있을 때 확인된 시설 최대 3곳의 LLM 직접 웹검색 → 작성일·원문·시설명/주소 검사 → 메인 화면의 별도 설명. 웹 조사 결과가 정량 점수/필수조건을 변경하지 않는다. 중요도만 재계산하면 기존 근거와 조사 결과를 재사용한다.

`POST /api/education-profile`은 편집한 학교급·과목·반경·충분한 개소 수·거리/중요도·통학 방식과 보완 조사 여부를 적용한다. 다른 분야/미지원 니즈는 보존한다. 여러 자녀의 동일 지표가 이미 따로 있거나 교육이 사용자 정의 그룹에 속하면 단일 편집기로 합치지 않는다. 니즈 모델의 고정 필드 `parameters`는 실제 모델 스키마에서도 보존되며 관련 없는 필드는 null 후 제거한다.

공통 원칙과 현재 제공처 범위는 [보완 조사 정책](research-policy.md), [공개 웹 조사](review-research.md)를 따른다. 현재 공개 원문 연결은 티스토리이며 모든 학원/웹 제공처의 자료 확보를 보장하지 않는다. 원문이 없으면 결과를 꾸며내지 않는다.

## 재현

~~~powershell
python -X utf8 -m tools.fetch_education --raw-dir data/raw/education/20260930
python -X utf8 -m tools.prepare_education --raw-dir data/raw/education/20260930
python -X utf8 -m app.web --env-file ../work/map-api-setup/.env
python -X utf8 -m unittest discover -s tests -p test_education.py
~~~

공공 상가 `data/processed/inventory.json` 준비가 선행한다. 신규 폴더 수집·행 수/해시·지역/학령/누락·자료 날짜 대조 후 서버를 다시 시작한다. 원본 응답의 행값을 JSON으로 보존하고 그 파일의 SHA-256을 manifest에 남긴다. 표준학교 다운로드 페이지 번호는 1부터다. 전체 교육 파일/원본/개인 입력/키는 Git 제외, 재현 코드와 출처·해시 메타데이터만 포함한다. 기본 bind는 `0.0.0.0:5173`이다. 실제 제출본 고정과 별도 환경 재현은 후속이다.
# 현재 AI 조사 연결 (2026-10-03)

학원 과목·학년·수업 형태 선호는 자동으로 공식 웹 사실 확인에 연결한다. 등록자료에서 학령이 불명확한 시설은 점수의 확인 시설로 만들지 않고 조사 후보로 유지한다. [시설 이용 조건 조사](facility-fact-research.md)를 따른다. 본문의 정량 모듈의 등록시설 수와 학교 거리 한계는 유지한다.
