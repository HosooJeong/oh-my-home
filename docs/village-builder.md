# 나의 생활 마을 — 첫 구현

2026-10-01 사용자 승인 후 앱에 연결했다. `/`는 새 마을, `/workspace`는 기존 M1~M6 분석, `/samples`는 표본 지도다. 상위 프로젝트의 결정/검증 기준본은 복제하지 않는다.

## 조작과 전달

주소 없이 찾아보기 / 집 한 곳 분석 / 여러 집 비교 중 진입을 고른다. 주소·동네는 초안 메모이며 좌표 변환은 하지 않는다. 카테고리 버튼으로1~6개를 구성하고 블록을 집 가까이/멀리 끌어 중요도를 정한다. 선택된 버튼을 다시 누르면 제외하고 마지막 하나는 유지한다.

블록을 직접 끌어 옮기는 동안 집과의 바닥거리로 중요도와 백분율이 자동 갱신된다. 선택창·중요도 버튼/슬라이더·중복 비중·개수 표시·움직임 토글·지도 바로가기는 제거했다. 백분율은 마을 블록 라벨에만 표시하고, 카테고리 선택과 ‘배치 완료’를 남겼다. 빈 바닥 좌우 드래그 또는 회전 아이콘은 수평 카메라만 바꾼다. 기울기 고정/블록 이동 중 회전 잠금, 확대·축소, F 전체화면과 시스템의 감소된 모션 설정은 유지한다. 문자 기호 대신 신규 SVG 선 아이콘을 쓴다.

사용자가 ‘배치 완료’를 눌러 배치 종료를 정한 뒤에만 상세 조건 화면으로 넘어간다. 한 개 이상 선택하면 완료할 수 있고, 모든 블록에 별도 드래그를 강제하지 않는다. 상세 화면에서는 마을/배치 도구를 숨기고 숨긴 3D 화면의 렌더링을 멈춘다. 선택한 카테고리만 중요도 순서로 하나씩 질문하고 답변/모름·이전·배치 복귀를 보존한다. 검토 후 /analysis로 전달하며 니즈 정리가 자동 시작된다. 세 진입점·필요 인터뷰·지도 위치 선택/자동 탐색·단독 결과/비교·모듈 진행의 현재 범위는 [새 분석 흐름](analysis-flow.md)을 따른다. 마을 배치 자체는 모델·검색을 호출하지 않는다.

## 계산·상태

- 가상 바닥 X/Z에서 집까지 거리다. 실제 주거/시설 거리 단위가 아니다. 회전·장식은 중요도에 영향이 없다.
- 거리 단계1~5 대표 반지름2.4/3.6/4.8/6.0/7.2, 중간값 경계, raw 중요도100/80/60/40/20은 이번 구현 선택이다. 바닥0.5 격자로 붙이고 겹침·집 중앙·바깥 경계를 보호한다.
- 백분율은 **가격 참고를 제외한 상대 반영 비중**으로 소수 첫째 자리 합100%. 같은 중요도도 반올림 때문에0.1 차이가 날 수 있다. 집·비용은 별개로 기존 평가에 **가중치0/실거래 참고**로 전달한다. 실제 점수/미확인 비중은 분석 결과에서 확인한다.
- 순수 상태/계산은 `village-model.mjs`, DOM/3D는 `village.mjs`다. 단일 캔버스와 로컬 Three.js0.180.0을 쓴다. 원본 해시·MIT 고지는 [출처](../THIRD_PARTY_NOTICES.md)를 따른다.
- 집/카테고리·소품의 정교한 부품 모델은 `village-models.mjs`에서 조립한다. 둥근 모서리·돌기/테두리·벽돌 경계·지붕 타일·창문·작은 휠/시계/탁구대, 플라스틱 재질/로컬 조명 맵과 부품 인스턴싱을 추가했다. 확대 상한은2.8로 늘렸다. 모델 좌표/크기와 선호 계산을 분리하며 외부 3D 자산은 없다.
- `sessionStorage`의 `saljari.village.v1`에 진입/메모/선택/좌표/답변을 보존한다. 탭 초안이며 서버/영구 계정 메모리는 아니다. 손상·알 수 없는 카테고리/좌표를 제거하고 저장 불가를 알린다. 제외·재추가 후에도 답변을 유지한다.
- 기존 니즈 결과는 선택 분야만 유지하고 배치 가중치를 적용한다. 빠진 분야/양수 중요도의 세부 조건이 없으면 재입력을 요청한다. 집·비용만 선택하면 점수 조건 없이 실거래 참고 결과로 진행한다.
- `window.render_game_to_text()`/`window.advanceTime(ms)` 및 DOM `#scene-state`로 개발 중 모드·배치·회전·드래그 상태를 확인한다.
