# 나의 생활 마을 — 첫 구현

2026-10-01 사용자 승인 후 앱에 연결했다. `/`는 새 마을, `/workspace`는 기존 M1~M6 분석, `/samples`는 표본 지도다. 상위 프로젝트의 결정/검증 기준본은 복제하지 않는다.

## 조작과 전달

후보·주소 있음 / 처음 탐색 두 진입을 고른다. 주소·동네는 초안 메모이며 좌표 변환은 하지 않는다. 카테고리 버튼으로1~6개를 구성하고 블록을 집 가까이/멀리 끌어 중요도를 정한다. 선택된 버튼을 다시 누르면 제외하고 마지막 하나는 유지한다.

블록 클릭 또는 아래 선택창으로 조절 대상을 바꾼다. 버튼/슬라이더도 같은 거리 계산을 사용한다. 빈 바닥 좌우 드래그 또는 회전 버튼은 수평 카메라만 바꾼다. 기울기 고정/블록 이동 중 회전 잠금, 확대·축소, 움직임 끄기, F 전체화면을 제공한다. 감소된 모션 설정을 존중한다.

선택한 카테고리만 중요도 순서로 짧은 질문을 보여준다. 답변/모름과 이전·배치 이동을 보존한다. 완료 후 기존 자연어 요청에 전달하며 사용자가 ‘AI로 조건 정리’를 눌러야 모델 작업이 시작된다. 새 마을 자체는 AI·검색·지도 API를 호출하지 않는다.

## 계산·상태

- 가상 바닥 X/Z에서 집까지 거리다. 실제 주거/시설 거리 단위가 아니다. 회전·장식은 중요도에 영향이 없다.
- 거리 단계1~5 대표 반지름2.4/3.6/4.8/6.0/7.2, 중간값 경계, raw 중요도100/80/60/40/20은 이번 구현 선택이다. 바닥0.5 격자로 붙이고 겹침·집 중앙·바깥 경계를 보호한다.
- 백분율은 **배치 선호 상대 비중**으로 소수 첫째 자리 합100%. 같은 중요도도 반올림 때문에0.1 차이가 날 수 있다. 집·비용은 별개로 기존 평가에 **가중치0/실거래 참고**로 전달한다. 실제 점수/미확인 비중은 기존 결과에서 확인한다.
- 순수 상태/계산은 `village-model.mjs`, DOM/3D는 `village.mjs`다. 단일 캔버스와 로컬 Three.js0.180.0을 쓴다. 원본 해시·MIT 고지는 [출처](../THIRD_PARTY_NOTICES.md)를 따른다.
- `sessionStorage`의 `saljari.village.v1`에 진입/메모/선택/좌표/답변을 보존한다. 탭 초안이며 서버/영구 계정 메모리는 아니다. 손상·알 수 없는 카테고리/좌표를 제거하고 저장 불가를 알린다. 제외·재추가 후에도 답변을 유지한다.
- 기존 니즈 결과는 선택 분야만 유지하고 배치 가중치를 적용한다. 빠진 분야/양수 중요도의 세부 조건이 없으면 재입력을 요청한다. 집·비용만 선택하면 초안을 유지하지만 기존 양수 가중치 계약 때문에 단독 결과 연결은 후속이다.
- `window.render_game_to_text()`/`window.advanceTime(ms)` 및 DOM `#scene-state`로 개발 중 모드·배치·회전·드래그 상태를 확인한다.

## 실행·짧은 검증

기존 자료/키 준비 후 `python -X utf8 -m app.web --host 0.0.0.0 --env-file ../work/map-api-setup/.env`. 자료·Python 준비는 README를 따른다. npm 빌드/Node 서버는 필요 없으며 아래 Node 명령은 개발 검사다.

~~~powershell
node tests/village-model.test.mjs
node --check app/static/village.mjs
node --check app/static/app.js
python -X utf8 -c 'import sys, unittest; sys.path.insert(0, "tests"); unittest.main(module="test_living", argv=["unittest", "HttpTests", "-v"])'
~~~

순수 계산/초안/전달8개와 HTTP3개 통과. 실제 브라우저에서 두 진입/6→1→3개·블록 선택/드래그·회전 불변·대체 조절·선택 질문/답변 보존·기존 요청 전달/지도 초기화,390px 배치를 확인했다. 입력 함수 변수 이름 충돌과 모바일 flex 높이를 수정했고 수정 후 새 콘솔 오류/경고0. 전체 M1~M6 회귀·신규 실제 모델 호출·휴대폰/성능·3D 실패 재현은 하지 않았다.
