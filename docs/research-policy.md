# 공공 근거와 LLM 보완 조사 기준

2026-09-30 사용자 확정: 검증된/공공데이터가 있으면 우선 사용하고, 정성적 설명이나 판단에 필요한 보완은 LLM을 파이프라인에 넣어 직접 검색한다. 오래되거나 부정확한 자료는 배제한다. 숫자 기간·검사 방법·현재 제공처 범위는 구현 선택이며 사용자 개인 선호가 아니다.

1. 공식 조회로 확인된 거리·수·등록 정보는 프로그램이 계산한다. LLM이 데이터 공백을 숫자로 채우거나 다른 분야로 가중치를 옮기지 않는다.
2. 니즈 정리에서는 검색을 끈다. 보완 요청이 있을 때 비교 뒤 웹 조사 작업을 시작한다. 현재 M1 상가/M4 학원/M5 공식 지역 게시글/M6 사설 취미시설에 연결했고 M2 경로 조사는 후속이다. 요청된 보완은 한 작업에서 순차 실행하고 실패를 분야별로 남긴다. 재가중치는 추가 검색 없이 수행한다.
3. 시설의 변하기 쉬운 정성 정보는 작성 **730일 이내**를 초기 허용 기간으로 사용한다. 실제 원문의 작성일 메타데이터/Article JSON-LD와 대조한다. 수정일·수집일로 작성일을 대체하지 않는다. 작성일 없음/여러 게시일 충돌/미래/기간 밖이면 제외한다. 필요하면 분야별 정책을 추가한다.
4. LLM이 직접 검색/원문을 읽고 URL·작성일·짧은 원문 인용·해석·같은 시설 근거를 반환한다. 서버가 원문을 다시 읽어 시설명과 도로명 주소, 인용 문구를 대조한다. 검색 요약/접근 불가/다른 지점/협찬·체험단 표시/조작된 인용은 제외한다. 출처당 20단어, 인용 160자, 시설당 최대 2개다.
5. 공식 정보·일부 작성자의 경험·AI 해석·미확인을 구분한다. 후기 몇 건을 전체 만족도/현재 상태/객관적 품질로 일반화하지 않는다. 원문 문구 대조는 모든 주장에 대한 사실검증이나 독립성 보장이 아니다.
6. 결과는 메인에 별도 정성 근거로 모인다. 정량 점수·순위·필수조건 통과 근거로 자동 승격하지 않는다. 인용 가능 자료가 없으면 빈 결과로 남긴다. M6의 작성일 없는 운영자 소개는 주소/종목 대조 후 발견 후보만으로 남길 수 있지만 인용/최신 이용 근거로 채택하지 않는다. 작성일 없는 이용 경험은 제외한다.

`app/research_policy.py`가 공통 프롬프트와 원문 수용 검사를 관리한다. 시설 경험은 티스토리, M5 공식 지역 자료는 진주시청 개별 게시글이다. robots.txt·크기/시간 제한·링크 검사를 유지한다. 시설은 공공 이름/주소와 비식별 기능 질문, 지역은 공식 행정동/선택한 문제·공개 질문을 전달하며 카카오/네이버 Local 응답·지도 리뷰·후보 좌표/개인 입력·키를 조사 모델에 전송하지 않는다. M5는 게시글 본문의 작성일·지역/문제 일치를 확인한다. 제공처 확장 시 원문 접근·권리·작성일/대상 식별을 확인한다. 인터넷의 모든 부정확한 주장을 자동 탐지한다는 의미는 아니다. [M5 범위](safety-environment.md)를 따른다.

M6는 일반 공개 HTTPS 원문에서 후보를 발굴하며 초기 제공처 제한과 원문·날짜·지점·종목 검사는 [여가 범위](leisure-accessibility.md)를 따른다. 해당 플랫폼의 블로그/공식 채널 전체 지원이나 발견 시설의 현장 영업·서비스 형태 확인 완료를 뜻하지 않는다.

기존 M1의 오래된/작성일 미확인 후기 허용은 이 정책으로 대체됐다. 과거 실행 기록의 2018년 인용은 역사적 검증 결과로 보존하며 현재 자료로 재사용하지 않는다. 자료 기준일/등록 연계일과 수집일의 구분·갱신은 [데이터 관리](data-maintenance.md)를 따른다.

R3에서는 공개 기능 질문을 분야/조건/시설에 연결해 전달한다. 자동 생활·교육 각1회, 안전1회, 취미1회를 같은 모델 슬롯에서 순차 실행할 수 있다(모두 요청/지원될 때 최대4회). 각 호출120초 제한과 기존 원문별 제한을 유지하며 전체 작업의 추가 총시간 상한을 만든 것은 아니다. 한 분야의 실패는 그 요청에 남기고 나머지 요청을 진행한다. `request_statuses`의 실행 완료/인용 수용 상태는 세부 조건의 충족 여부가 아니다. 이 문단은 R3 당시 범위다. 현재 질문별 관련성·형태·AI 해석의 수용은 아래 R4 검증을 적용한다.

R4는 [Codex 응답 검증](response-validation.md)을 추가했다. 로컬 원문 검사 이후 별도 검색 없는 의미 검토 최대1회/6인용/45초를 실행하고, 그 검토의 응답도 claim/질문 ID·타입·개수로 재검사한다. 원문을 확인한 사실과 모델의 의미 판단을 구분한다. 실패/모호함은 미확인이며 검토가 정량 점수나 필수조건을 확정하지 않는다. 실제 연결된 합성6사례와 공개 공식 검색1회(인용0)를 각각 검증했으며 실제 수용 웹 인용의 전체 흐름/실사용 오류 빈도는 미측정이다.
# 시설 사실 조사의 별도 정책 (2026-10-03)

과목·진료과 등은 [시설 사실 조사](facility-fact-research.md)로 확인한다. 날짜 없는 운영자 현행 안내는 직접 원문·상호·주소·인용 검증을 통과한 경우 갱신일 미확인으로 구분하며 조회일을 작성일로 대체하지 않는다. 본문의 날짜 필수 정책은 기존 방문 후기·공식 지역 기사에 유지한다.
