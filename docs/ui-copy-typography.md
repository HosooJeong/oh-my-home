# 화면 문구와 한글 폰트

2026-10-02 사용자 요청을 반영했다. 제품 문구는 가벼운 존댓말, 조작 이름은 짧은 명사/동사로 통일한다. 제목·주소 검색·선택 목록·주요 버튼이 있으면 같은 조작을 설명하는 문장을 덧붙이지 않는다. 시각적 라벨을 덜어내도 입력의 접근 가능한 이름과 오류/상태 영역은 유지한다.

지도 화면의 집 주소 제목과 선택 안내를 제거하고 좌표 대체 입력은 없앴다. 카카오 지도 로더는 페이지당 SDK 요청을 공유하며 설정/스크립트/SDK 로드의 실패·시간초과를 구분해 실패 상태를 해제하고 재시도한다. 오류와 다시 불러오기 버튼은 실패했을 때만 표시한다. 두 지점을 선택한 뒤 폭이 바뀌면 모두 보이도록 범위를 재조정한다.

총평·평가 사유·출처·원문과 미확인 범위, 가격 참고 상태는 유지한다. 반복되는 로딩 설명은 제거하고 이전 /workspace의 해석 안내는 접힌 참고 항목으로 이동했다. 평가 수식과 조건 비중, 내부 모델 요청 구성은 변경하지 않았다. 인용·사용자 원문·모델의 원래 반환 내용은 문구 편집 대상에서 제외한다.

기존 레고 색상과 구조를 유지하며 제목/브랜드는 SUITE v2.0.4, 본문/입력/버튼은 SUIT v2.0.5를 사용한다. 제목 650, 버튼 600, 본문 400을 기본으로 하며 크기·자간·줄바꿈을 조정했다. 가변 WOFF2를 원본 그대로 로컬 제공하고 font-display:swap과 본문 폰트 preload를 사용한다. 외부 폰트 CDN은 요청하지 않는다. 출처·해시·SIL OFL 1.1 원문은 app/static/vendor/fonts/README.md와 두 LICENSE.txt에 보존한다.

관련 Node47 검사 및 실제 localhost:5173 카카오 검색/선택/지도 클릭, 세 진입 화면·생활 입력·1280/390 viewport 폰트/넘침을 확인했다. 새 실제 모델/웹 조사 및 분석 결과 화면 전체 재실행, 실폰·접근성 도구·시각적 만족도/FPS 검증은 아니다.
