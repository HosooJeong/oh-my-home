# M3 집·비용의 범위

2026-09-30 사용자 지시: 같은 지역·인접한 위치에서도 집값 편차가 크므로 실제 매물 추천으로 확장하지 않고 가격이 다른 분야 비교를 과도하게 좌우하지 않도록 한다. 구현 선택은 **현재 가격 점수 반영 0, 과거 거래 참고 분포 제공**이다. 특정 낮은 가중치 숫자를 사용자가 확정한 것은 아니다. 향후 가격을 점수에 연결하려면 사용자가 확인한 거래·면적·주택 조건과 적절한 공간 근거부터 별도 검토한다.

메인은 생활/교통 평가 모듈과 별개로 집·비용 참고 모듈을 호출해 `references`로 통합한다. 참고 결과는 `Evidence`로 변환하지 않으므로 점수, 필수조건 판정, 분석 지점 선별에 사용되지 않는다. 명시적인 실제 집의 예산/주택 조건은 미지원 조건으로 남으며 지역 중앙값으로 통과시키지 않는다. 미지원 활성 조건이 있으면 기존 평가 규칙대로 순위·자동 선별을 유보한다.

## 실제 자료

- [국토교통부 실거래가 공개시스템의 공개 CSV 자료제공](https://rt.molit.go.kr/pt/xls/xls.do?mobileAt=), 2026-09-30 조회. 공개 다운로드 화면의 지역 응답으로 진주시 법정 시군구 코드 **48170** 확인. API 활용신청·키 없이 공개 CSV 경로 이용.
- 아파트 계약일 **2025-09-01~2026-08-31**. 진행 중인 9월을 제외한 1년은 구현 선택이며 완전한 신고·정정 반영을 보장하지 않는다.
- 매매 원본 **4,739행** 중 해제 **280행** 제외 → **4,459행**. 전월세 **4,638행** → 전세 **2,198행**·월세 **2,440행**. 총 **9,097행**, 잘못된 행으로 분리된 건수 0, 33개 법정동/읍면리 주소.
- CP949, 원본 만원 단위를 **KRW 정수**로 변환. 원본 파일명·CSV 행·계약일·유형·면적을 정규화 자료에 보존하고 단지명/개별 집 추천 목록은 제품에 노출하지 않는다. 해시·조회 시각은 [고정 자료 메타데이터](../data/reference/housing-snapshot.json)에 기록한다. 원본/정규화 전체는 Git 제외.

공식 자료의 유의사항을 따른다. 법적 효력이 없는 참고 자료, 실시간 변경/해제 가능, 계약일 기준이다. 이 시제품의 분포는 공식 통계가 아니다. **외부 통계 공개에는 신고일 기준 공식통계를 사용해야 한다는 안내**를 출처/제품 한계에 명시한다. 공개 배포와 통계 보고서 작성 전 해당 목적의 공식 통계를 별도 확보한다. [매매 API](https://www.data.go.kr/data/15126469/openapi.do)·[임대 API](https://www.data.go.kr/data/15126474/openapi.do)는 공식 후보 경로를 확인했으며 이번 실행에서는 사용하지 않았다. API의 이용조건을 공개 CSV의 권리 조건으로 대신 적용하지 않는다.

## 조회와 해석

웹 폼/API에서 매매/전세/월세, 법정동 주소, 전용면적 **최소 이상·최대 미만**, 임대 신규/갱신/전체로 선택한다. 준비한 기간은 고정이며 새 기간은 원본을 다시 준비한다. 각 표본의 건수와 중앙값·25/75백분위·최소/최대, 매매는 ㎡당 금액도 표시한다. 분위수는 정렬 표본의 `(n-1)*p` 위치 선형 보간이다. 5건 미만은 가격 요약 유보, 0건/원본 없음은 자료 없음이며 0원으로 변환하지 않는다. 5건 기준은 구현상 최소 표시 기준으로 대표성/신뢰수준 보장이 아니다.

월세는 보증금·월세금을 각각 보여 주고 전세/월세·월 비용으로 임의 전환하지 않는다. 두 중앙값을 실제 한 계약의 조합으로 해석하지 않는다. 공공임대/민간, 연식·층·단지 차이가 남아 있고 분포가 넓은 이유를 하나로 단정하지 않는다. 원본이 법정동 주소이며 지도의 SGIS 센서스 행정동 **38030** 및 분석 지점과 연결되지 않아 후보별 집값을 추정하지 않는다.

AI 니즈 지침은 명시된 거래 방식 `housing_tenure=sale/jeonse/monthly`, 예산/면적/주택유형을 문맥으로 보존하도록 변경했다. 메인의 기본 참고 조회는 명시된 거래 방식만 사용하고, 면적/지역/계약 구분은 현재 직접 조회 폼에서 확인한다. 금액 점수·예산 판정은 생성하지 않는다. 이번 신규 실제 제품 모델 호출은 없으며 변경한 프롬프트의 실제 모델 응답은 미검증이다. 가격만 조사하려는 경우 직접 조회 폼을 사용할 수 있다.

## 준비 및 갱신

저장소 루트에서:

~~~powershell
python -X utf8 -m tools.fetch_housing --raw-dir ../work/housing-research-새조회일 --start 2025-09-01 --end 2026-08-31
python -X utf8 -m tools.prepare_housing --sale ../work/housing-research-새조회일/jinju-apartment-sale-202509-202608.csv --rent ../work/housing-research-새조회일/jinju-apartment-rent-202509-202608.csv
python -X utf8 -m app.web --env-file ../work/map-api-setup/.env
~~~

현재 원본 경로는 `../work/housing-research/`이며 같은 원본의 JSON manifest가 필요하다. 기존 원본 경로를 `prepare_housing`에 넣으면 현재 자료를 재생성할 수 있다. 수집기는 기존 파일을 덮어쓰지 않고, 최대 1년/진주시 아파트 2개 파일로 제한한다. 공식 화면/CSV 스키마가 바뀌면 조용히 다른 자료를 적재하지 않고 검토를 요구한다. 준비 시 해시·기간·지역·유형을 대조하고 해제/거절 행을 기록한다. 수집 도구는 확인된 공개 경로를 재현하도록 작성했으며 신규 폴더를 쓰는 정식 CLI 재다운로드는 별도 미실행이다.
